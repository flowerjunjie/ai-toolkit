### V2EX / 中文社区
```
【开源发布】AI Toolkit - 让本地AI开发更简单

大家好，我刚刚发布了一个开源项目 AI Toolkit，这是一个命令行工具，
专门用于管理本地AI模型。

为什么要做这个？
现在本地运行大模型越来越流行（Ollama、LM Studio等），但缺少一个
统一的工具来管理这些模型和相关的Prompt、RAG等功能。

主要功能：
1. 模型管理 - 类似 Docker 的体验，pull/run/list/ps
2. Prompt模板 - 变量支持，团队协作
3. RAG知识库 - 一键搭建，支持多种文档格式
4. 性能测试 - 对比不同模型的速度和质量

完全开源，MIT协议，欢迎star和贡献！

GitHub: https://github.com/yourusername/ai-toolkit
```
