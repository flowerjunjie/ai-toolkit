# 赞赏码图片说明

请将你的赞赏码图片放在这个目录下：

## 需要的图片

1. **wechat-pay.jpg** - 微信赞赏码
2. **alipay.jpg** - 支付宝收款码

## 操作步骤

1. 将你的微信赞赏码图片重命名为 `wechat-pay.jpg`
2. 将你的支付宝收款码图片重命名为 `alipay.jpg`
3. 将这两个图片放到这个目录 (`docs/images/`)
4. 提交到 GitHub

## 图片要求

- 格式：JPG 或 PNG
- 尺寸：建议 300x300 像素
- 大小：建议小于 1MB
- 清晰：确保二维码可以扫描

---

**注意**：这些图片将公开在 GitHub 仓库中，任何人都可以看到。
